<h1> Heading </h1>

This is an example of an h1 element.

The result is a large, bold heading.

Heading

  • Use one main <h1> per page.
Do Don't Advice
<h1>Site title</h1> <h1>Site title</h2> Always use matching opening and closing tags.
<h1>Welcome to my site</h1> <h1></h1> Put meaningful text inside the heading.
Use one main <h1> per page Use multiple <h1> elements for every section Keep the main page heading unique and semantic.
Use <h1> for the top-level title Use <h1> for small paragraph text Use headings for structure, not styling.
